









q- what is naming convention in java 
ans- 
Here are key Java naming conventions:

Packages: All lowercase (e.g., com.example.myapp).
Classes: PascalCase (start with uppercase, no underscores) (e.g., MyClass).
Methods: camelCase (start with lowercase) (e.g., calculateSum).
Variables: camelCase (e.g., userName).
Constants: UPPERCASE_WITH_UNDERSCORES (e.g., MAX_VALUE).
Interfaces: PascalCase, like classes (e.g., Runnable).
Enums: PascalCase for names, constants inside all uppercase (e.g., Color.RED).
